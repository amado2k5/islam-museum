The megaplan — where we are going

Goal: the whole of Islam — faith, civilization, peoples, places, texts, objects, living culture — as an Arabic-first knowledge graph in git, published as a static museum. The work splits into: (a) prose coverage of what the graph already knows, (b) entity coverage of what the books still hold, (c) new books still to harvest.

  1. Prose backlog (biggest lever): ~13k entities lack Arabic prose — buildings (~5.5k), works (~1.2k), second-tier persons/events (~6k). Buildings: most are Wikidata imports the sources never name — realistic target is the famous subset; works: Kashf al-Zunun + Fihrist lanes; persons/events: tabaqat + tarikh lanes.
  2. Entity backlog: unmined harvest — juz' 2/3/10/11 of Subki; rijal set (Tahdhib al-Kamal, Mizan, Jarh wa'l-Ta'dil, Thiqat Ibn Hibban, al-Tarikh al-Kabir); tarikh set (Tabari, Tarikh Dimashq, Shadharat al-Dhahab); geography set (Mu'jam al-Buldan, Mu'jam ma Ustu'jima); 'alam al-Zirikli for modern-era persons; khitat al-Maqrizi + Azraqi + Wafa' al-Wafa' for buildings/places.
  3. Gaps needing new scans: Tarikh Baghdad vols. 10 (first ~100pp) & 11 waw section; Kashf vol. 2; al-Kamil AH 41-294; Isaba residual.
  4. Translation parity: en/ur prose lags ar on ~300 files; rule is now trilingual-per-commit so the gap only shrinks.

Suggested prompts this data supports: "continue" (next batch on the active lane), "fill prose for buildings/places", "open the rijal lane", "open the works lane (Kashf/Fihrist)", "list books to scan next".
