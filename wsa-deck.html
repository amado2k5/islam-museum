2 · Technology architecture & open data

Serverless Static Architecture & Open Science

Stack

Astro · Svelte · Tailwind CSS · Pagefind search, hosted on GitHub Pages behind the Cloudflare edge.

Privacy & performance

Zero server overhead; sub-50 ms loading†; no database; no tracking scripts or client cookies. Every page is a static file.

Machine-readable

Entities as YAML data and Markdown prose in git, with a public JSON API at /api/v1/ and graph exports.

Language support

Bilingual core content (Arabic & English) with a trilingual interface (Arabic, English, Urdu).

Open licensing grid

CC0 1.0
Public-domain datasets: structured facts, identifiers, relations and schemas.
CC BY-SA 4.0
Prose content in all languages, with citations to the underlying sources.
MIT
Source code for the site, build pipeline and validators.

Every entry is cited to its sources; third-party licences are recorded per item.

Family heritage tribute

Conceived as a personal digital public commons, extending the scholarly legacy of the founder’s late father, Hamdy Abdel Aal (Islamic scholar & Dar Al-Qalam author), and his late mother, Fatma Alkawokgy (lifelong cultural archivist).
