# Code of Conduct

We follow the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in full: be welcoming, respectful and constructive; harassment of any kind is not tolerated. Report concerns to the maintainers via a private GitHub security/contact channel or the address listed in `GOVERNANCE.md`.

## Museum clause

This project documents a faith and a civilization that many contributors hold dear and others study from outside.

- Respect for all traditions, schools and none. Use people's own self-designations.
- No proselytising and no polemics in any project space: issues, pull requests, discussions, comments.
- Assume good faith. Cite rather than argue; when sources disagree, record the disagreement in a `perspectives` block.
- Sectarian slurs, dehumanising language and mockery of beliefs are removed.
