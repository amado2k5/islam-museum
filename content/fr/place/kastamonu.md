## Vue d'ensemble
Kastamonu est une ville de Turquie, chef-lieu de la province du même nom. Elle n'apparaît pas dans les deux premiers volumes du Mu'jam al-buldan de Yaqut ; cette page se base donc sur les informations du iDAI.gazetteer. {cite:idai-gazetteer 2090159}
