## Vue d'ensemble
Prešov est une ville de Slovaquie. Elle n'apparaît pas dans les deux premiers volumes du Mu'jam al-buldan de Yaqut ; cette page se base donc sur les informations du répertoire géographique des Pléiades. {cite:pleiades 128495}

## Dans le répertoire des Pléiades
Pléiades, le répertoire géographique ouvert des lieux antiques, recense cet endroit sous le nom de « Prešov » (Pléiades n° 128495), classé comme un lieu habité, dont la localisation est attestée de 30 av. J.-C. à 640 apr. J.-C., soit durant les périodes romaine et de l'Antiquité tardive. Aucun nom n'y est mentionné. La description indique seulement qu'il s'agit d'un lieu antique cité dans l'Atlas de Barrington, carte 13, case G4, et que le répertoire de l'Atlas le désigne sous le nom de « Prešov, SVK ». {cite:pleiades 128495}
