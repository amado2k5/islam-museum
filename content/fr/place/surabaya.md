## Vue d'ensemble
Surabaya est la deuxième plus grande ville d'Indonésie et son principal port, située à Java oriental. Ville moderne, elle n'apparaît pas dans les deux volumes du Mu'jam al-buldan de Yaqut, consultés pour ce musée ; cette page se fonde donc uniquement sur les informations du répertoire géographique allemand.
