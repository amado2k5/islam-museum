## Vue d'ensemble
Kayseri est une ville de Turquie, l'ancienne Césarée de Cappadoce. Les entrées sous le nom de Qaysariyya dans les deux volumes du Mu'jam al-buldan de Yaqut, consultées pour ce musée, ne concernent pas cette ville ; cette page se base donc uniquement sur les informations du répertoire géographique allemand.

## Dans le iDAI.gazetteer
Le répertoire iDAI de l'Institut archéologique allemand recense ce lieu sous le numéro 2285308, à la fois comme site archéologique et comme lieu habité, sous le nom latin privilégié de « Caesarea in Cappadocia ». Il est rattaché à la province de Kayseri.
