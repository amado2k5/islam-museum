## Vue d'ensemble
Sinop, connue dans les ouvrages anciens sous le nom de Sinope, est une ville de Turquie. Elle n'apparaît pas dans les deux premiers volumes du Mu'jam al-buldan de Yaqut ; cette page se base donc sur les données de l'iDAI.gazetteer. {cite:idai-gazetteer 2280255}

## Dans le iDAI.gazetteer
Le répertoire iDAI de l'Institut archéologique allemand recense ce lieu sous le numéro 2280255, avec le nom privilégié « Sinope », classé comme lieu habité ; son répertoire parent est le numéro 2232771. Parmi les noms qu'il répertorie figurent « Sanub », « Sinub » et « Sınob », « Σινώπη » en grec et « Sinop » en anglais et en français. Il relie ce lieu à GeoNames n° 739600, à un lieu d'Arachne et aux archives de Zenon. {cite:idai-gazetteer 2280255}
