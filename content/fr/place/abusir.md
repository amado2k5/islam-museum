## Vue d'ensemble
Abousir, à Gizeh en Égypte, est un site archéologique, une nécropole de l'Ancien Empire qui desservait l'ancienne ville de Memphis. Les deux premiers volumes du Mu'jam al-buldan de Yaqut mentionnent Abousir pour quatre villages d'Égypte, mais il est impossible de les rattacher à ce site précis ; cette page se base donc sur les informations du répertoire géographique des Pléiades. {cite:pleiades 195443086}

## Dans le répertoire des Pléiades
Pléiades, le répertoire géographique ouvert des lieux antiques, recense ce site sous le nom d'« Abu Sir » (Pléiades n° 195443086), classé comme cimetière, avec une datation allant de 2670 à 2168 avant notre ère, durant l'Ancien Empire. On y trouve également le nom sous les formes « Abu Sir », « Abusir », « Abū Şīr » et « ابوصير », entre 1700 et 2100 apr. J.-C., une limite supérieure indéterminée pour la période moderne. La description indique qu'il s'agit d'une nécropole de l'Ancien Empire desservant l'ancienne ville égyptienne de Memphis. {cite:pleiades 195443086}
