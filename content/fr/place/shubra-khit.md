## Vue d'ensemble
Shubra Khit est une ville du gouvernorat de Beheira, en Égypte. Elle n'apparaît pas dans les deux premiers volumes du Mu'jam al-buldan de Yaqut ; cette page se base donc sur les informations du iDAI.gazetteer. {cite:idai-gazetteer 2773018}
