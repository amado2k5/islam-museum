## Vue d'ensemble
Tuz Khormato est une ville d'Irak. Elle n'apparaît pas dans les deux premiers volumes du Mu'jam al-buldan de Yaqut ; cette page se base donc sur les informations du répertoire géographique des Pléiades. {cite:pleiades 320150993}

## Dans le répertoire des Pléiades
Pléiades, le répertoire géographique ouvert des lieux anciens, répertorie ce site sous le nom de « Ṭūz Khūrmātū » (Pléiades n° 320150993), classé comme lieu de découverte. Il mentionne un nom sous les formes « Ṭūz Khūrmātū » et « طوز خورماتو », entre 1700 et 2100 apr. J.-C., une limite supérieure ouverte pour la période moderne. Sa description indique seulement qu'il s'agit du lieu de découverte d'une inscription cunéiforme. Sa localisation repose sur deux sources : OpenStreetMap et les données CIGS. {cite:pleiades 320150993}
