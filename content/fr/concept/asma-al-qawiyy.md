## Vue d'ensemble
al-Qawiyy — Le Fort. C'est le nom numéro 53 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra à al-Tirmidhi {cite:jami-al-tirmidhi} ; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l'explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-11-66|11:66]]، [[passage/quran-28-26|28:26]]، [[passage/quran-42-19|42:19]].

## Dans la Sunna
D'après Abou Hourayra : « Dieu a quatre-vingt-dix-neuf noms, cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. D'autres versions mentionnent ce nom, notamment : [[passage/muslim-2664|2664 et]].
