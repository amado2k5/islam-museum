## Vue d'ensemble
al-Qayyum — Le Soutien. C'est le nom numéro 63 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra à al-Tirmidhi {cite:jami-al-tirmidhi}; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à expliquer ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-2-255|2:255]]، [[passage/quran-20-111|20:111]]، [[passage/quran-3-2|3:2]].

## Dans la Sunna
D'après Abou Hourayra : « Dieu a quatre-vingt-dix-neuf noms, cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. Parmi les hadiths mentionnant ce nom, on trouve : [[passage/muwatta-1-583|1.583]].
