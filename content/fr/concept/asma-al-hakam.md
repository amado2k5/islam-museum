## Vue d'ensemble
al-Hakam — Le Juge. C'est le nom numéro 28 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra à al-Tirmidhi {cite:jami-al-tirmidhi}; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à expliquer ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-12-40|12:40]]، [[passage/quran-12-67|12:67]]، [[passage/quran-19-12|19:12]]، [[passage/quran-28-70|28:70]]، [[passage/quran-28-88|28:88]]، [[passage/quran-6-57|6:57]]، [[passage/quran-6-62|6:62]].

## Dans la Sunna
Abou Hourayra rapporte : « Dieu a quatre-vingt-dix-neuf noms — cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}.
