## Vue d'ensemble

Jins dans cette langue signifie une sorte de n'importe quoi ; parmi les juristes, il désigne un ensemble de différents types. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.6545}

## Son effet sur le zakat, la riba et le salam

Les animaux ou cultures d'un même type sont ajoutés vers le seuil, tandis que les espèces différentes ne sont pas ajoutées, donc le bétail n'est pas ajouté aux chameaux. Dans les ventes ribawi, la similarité ou la différence de type détermine la règle. Dans le salam (vente anticipée), le type de l'objet promis doit être nommé. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.6546} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.6547} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.6548}
