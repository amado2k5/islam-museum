## Vue d'ensemble
as-Salam — La Source de la Paix. C'est le nom numéro 5 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra rapporté par al-Tirmidhi {cite:jami-al-tirmidhi} ; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l'explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-10-25|10:25]]، [[passage/quran-4-94|4:94]]، [[passage/quran-5-16|5:16]]، [[passage/quran-59-23|59:23]]، [[passage/quran-6-127|6:127]].

## Dans la Sunna
Abou Hourayra rapporte : « Dieu a quatre-vingt-dix-neuf noms — cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. Les rapports mentionnant ce nom incluent : [[passage/bukhari-3326|3326]], [[passage/muslim-0054|54]], [[passage/muslim-0397|397]], [[passage/muslim-0591|591]], [[passage/muslim-2432|2432]], [[passage/muwatta-1-064|1,64]], [[passage/muwatta-1-240|1,240]], [[passage/muwatta-1-241|1,241]].
