## Résumé
Raqm dans le lexique est le tissage du tissu ; techniquement, c'est la marque qui indique le prix pour lequel une vente a lieu, ou le prix inscrit sur le tissu. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.8939} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.8940} Une vente au prix écrit est valable lorsque les deux connaissent le prix ; lorsque les deux sont ignorants, il est nul selon la majorité, et les Hanbalis le considèrent valable si la partie ignorante apprend le prix avant de se séparer. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.8940} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.8941} Un hadith interdit les images dans les maisons mais excepte une marque sur drap. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.8941}
