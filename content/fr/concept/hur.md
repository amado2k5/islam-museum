## Vue d'ensemble
Les hur al-'ayn dans la conception islamique sont parmi les bénédictions promises du paradis aux croyants, mentionnées dans les chapitres interprétant la description du paradis {cite:tafsir-ibn-kathir}.

## Dans les sources
Ibn Kathir mentionne le hur al-'ayn dans les chapitres sur les attributs du paradis {cite:tafsir-ibn-kathir}; le Sharh al-Tahawiyya détaille la félicité du paradis {cite:sharh-tahawiyya-ibn-abi-al-izz}.
