## Résumé
Khasa' est l'ablation des deux testicules ; les juristes l'utilisent pour prélever les testicules sans ou avec le pénis ; l'homme castré est celui dont le pénis est coupé, l'impuissant (unan) ne peut avoir de rapports sexuels, et le wijā' écrase les vaisseaux des testicules sans qu'on les retire. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7643} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7644} La castration d'un humain est interdite pour un enfant ou un adulte par accord, sur la base des rapports d'Ibn Mas'ud et de Sa'd ; le Prophète refusa à Uthman ibn Maz'un le célibat ; un rapport d'Umar dit « pas de castration dans l'islam » ; Ibn Hajar donne comme raisons que cela vainque la croissance de la descendance, torture le soi et modifie la création de Dieu. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7645} Pour les animaux : les Hanafi ne voient aucun mal à leur profit ; les Malikis l'acceptent pour les animaux comestibles sans antipathie ; les Shafiis l'accordent pour les animaux comestibles quand ils sont jeunes, s'ils ne tuent pas ; les Hanbalis autorisent la castration des moutons (une opinion n'aime pas cela), invoquant l'interdiction stricte du Prophète de castrer les animaux. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7646} Concernant l'annulation du mariage : les Hanafis traitent un mari castré comme un impuissant, avec un délai d'un an ; les Maliki laissent à l'épouse le choix si elle n'éjacule pas ; les Shafiis ont deux points de vue ; les Hanbali ne laissent pas le choix s'il peut avoir des rapports sexuels. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7646} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7647} Concernant les représailles pour les testicules : la plupart des juristes ordonnent des représailles lorsque les conditions sont valides ; les Shafiis considèrent l'écrasement ou la paralysie comme une coupe ; les Malikis n'autorisent aucune représaille pour l'écrasement ; les Hanafites ne trouvent aucun texte de représailles et exigent donc de l'argent du sang ; la lettre du Prophète à Amr ibn Hazm dit « l'argent du sang pour les testicules ». {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7647} Sur le prix de la coupe des testicules : un rapport d'al-Zuhri sur Sa'id ibn al-Musayyab affirme que la sunna fixe l'argent du sang complet pour le pénis et l'argent complet pour les deux testicules ; pour un testicule, la moitié, selon la plupart des érudits ; il est également rapporté qu'il a fixé deux tiers pour le gauche et un tiers pour le droit. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7648} Si les deux sont écrasés ou paralysés, la somme totale est due ; si les deux sont coupés et que la procréation est perdue, une seule somme ; si l'un est coupé et la procréation perdue, la moitié. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7648} Lorsque les deux testicules et le pénis sont coupés ensemble, la majorité donne deux sommes ; les Hanafis et les Hanbalis donnent deux si le pénis est coupé en premier, mais si les testicules sont coupés en premier, une somme pour eux et une évaluation équitable pour le pénis ; les Shafiis donnent une somme complète pour les testicules et pour le pénis dans chaque cas. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7648} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7649} Concernant le sacrifice d'un animal castré : les rapports indiquent que le Prophète sacrifia deux béliers castrés à cornes, tachetés ; al-Shawkani en tira l'intérêt ; les Hanafis permettent aussi bien des mâles castrés que des mâles entiers ; les Malikis préfèrent le mâle entier sauf si le mâle castré est plus gros ; les Shafiis et les Hanbalis permettent l'animal castré (les Hanbalis pas le mâle complètement émasculé). {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7649} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.7650}
