## Vue d'ensemble
al-Awwal — Le Premier. C'est le nom numéro 73 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra à al-Tirmidhi {cite:jami-al-tirmidhi}; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à expliquer ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, notamment dans les versets : [[passage/quran-50-15|50:15]] et [[passage/quran-57-3|57:3]].

## Dans la Sunna
D'après Abou Hourayra : « Dieu a quatre-vingt-dix-neuf noms, cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. Parmi les hadiths mentionnant ce nom, on trouve : [[passage/muwatta-1-174|1.174]].
