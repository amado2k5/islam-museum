## Vue d’ensemble
al-Awwal — Le Premier. C’est le nom numéro 73 dans l’énumération des plus beaux noms de Dieu du hadith d’Abu Hurayra chez al-Tirmidhi {cite:jami-al-tirmidhi} ; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l’explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, notamment en : [[passage/quran-50-15|50:15]]، [[passage/quran-57-3|57:3]].

## Dans la Sunna
Abu Hurayra rapporte : « Dieu a quatre-vingt-dix-neuf noms — cent moins un ; celui qui les énumère entre au Paradis » {cite:sahih-muslim}. Parmi les récits mentionnant ce nom : [[passage/muwatta-1-174|1.174]].
