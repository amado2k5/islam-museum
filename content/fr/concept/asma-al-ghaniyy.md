## Vue d'ensemble
al-Ghaniyy — Le Tout-Puissant. Il s'agit du 88e nom dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra rapporté par al-Tirmidhi {cite:jami-al-tirmidhi} ; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l'explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, notamment dans les versets suivants : [[passage/quran-10-68|10:68,]], [[passage/quran-22-64|22:64,]], [[passage/quran-31-26|31:26,]], [[passage/quran-35-15|35:15,]], [[passage/quran-47-38|47:38,]], [[passage/quran-57-24|57:24,]], [[passage/quran-6-133|6:133,]], [[passage/quran-60-6|60:6.]].

## Dans la Sunna
D'après Abou Hourayra : « Dieu a quatre-vingt-dix-neuf noms, cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. D'autres versions mentionnent ce nom, notamment : [[passage/muslim-2965|2965 et]].
