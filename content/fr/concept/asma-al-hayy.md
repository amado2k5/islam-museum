## Vue d'ensemble
al-Hayy — Le Vivant Éternel. C'est le nom numéro 62 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra à al-Tirmidhi {cite:jami-al-tirmidhi}; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l'explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-10-31|10:31]]، [[passage/quran-2-255|2:255]]، [[passage/quran-25-58|25:58]]، [[passage/quran-3-2|3:2]]، [[passage/quran-3-27|3:27]]، [[passage/quran-30-19|30:19]]، [[passage/quran-40-65|40:65]]، [[passage/quran-6-95|6:95]].

## Dans la Sunna
D'après Abou Hourayra : « Dieu a quatre-vingt-dix-neuf noms, cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}. Parmi les sources mentionnant ce nom, on trouve : [[passage/muslim-0779|779]], [[passage/muwatta-1-583|1 583]], [[passage/muwatta-2-598|598]].
