## Résumé
Dans le lexique, ittika' signifie s'appuyer sur quelque chose. Cela signifie aussi s'incliner d'un côté lorsqu'on est assis. Les juristes n'utilisent ce mot que dans ces deux sens. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1488}

## Différence avec istinad
Istinad, dans le lexique, signifie s'incliner uniquement par le dos. Il est donc plus étroit que pencher dans le premier sens, et il est distinct du second sens. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1488}

## Se pencher dans la prière
L'appui dans la prière, dans un sens ou dans l'autre, est permis à ceux qui ont une excuse valable, avec l'accord des juristes. Pour d'autres, l'inclination est détestée dans une prière obligatoire et permise dans une prière volontaire. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1488}

## S'appuyer sur une tombe, ou sur un objet contenant une image
S'appuyer sur une tombe est traité comme s'asseoir dessus. La majorité considère cela comme détesté ; les Malikis le permettent. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1488} S'appuyer sur quelque chose portant l'image d'un être vivant, comme un coussin, est abordé dans le cadre du mariage, dans la section consacrée au banquet de mariage. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1489}

## Où le sujet est traité
Les juristes traitent les règles à leur place : dans la prière, sous les actes détestés ; lors des funérailles, sous l'inhumation ; dans la pureté, selon les manières de se soulager ; dans la nourriture, le manjar en sous-manger ; dans les mosquées, selon ce qui est permis par nécessité ou pour ressusciter la terre morte ; et dans le mariage, sous le festin de mariage. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1488} {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1489}
