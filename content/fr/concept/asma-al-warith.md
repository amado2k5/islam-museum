## Vue d'ensemble
al-Warith — L'Héritier. C'est le nom numéro 97 dans l'énumération des plus beaux noms de Dieu dans le hadith d'Abu Hurayra rapporté par al-Tirmidhi {cite:jami-al-tirmidhi} ; Ibn Qayyim al-Jawziyya a consacré un chapitre de Jala' al-Afham à l'explication de ces noms {cite:jala-afham-ibn-qayyim}.

## Dans le Coran
Le nom apparaît dans le Coran, parmi eux : [[passage/quran-2-233|2:233]].

## Dans la Sunna
Abou Hourayra rapporte : « Dieu a quatre-vingt-dix-neuf noms — cent moins un ; quiconque les énumère entre au Paradis » {cite:sahih-muslim}.
