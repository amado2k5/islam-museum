## Résumé
Pour les juristes, l’ajr est la contrepartie d’un travail, qu’elle vienne de Dieu ou des êtres humains, même si la récompense divine est une grâce. Le mot désigne aussi le prix de l’usage d’un bien immobilier, par exemple pour loger dans une maison, ou d’un bien mobilier, par exemple pour se déplacer en voiture. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1592}

## Usage coranique
Le Coran appelle ajr ce qu’on donne à une femme qui allaite, ainsi que le don nuptial d’une femme. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1592}

## Où les juristes traitent la question
Les juristes traitent les questions d’ajr pour un travail ou pour l’usage d’un bien dans le cadre du louage. {cite:fiqh-mawsua-kuwaitiyya-noor-v3 p.1592}
