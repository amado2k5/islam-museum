## Le récit
Il parvint à Malik que des hommes d'entre les Compagnons virent en songe Laylat al-Qadr dans les dix dernières nuits, et le Messager de Dieu dit : je vois que vos songes se sont accordés sur le dernier tiers ; que celui qui la recherche la recherche dans le dernier tiers. L'éditeur critique note que Yahya l'a transmis comme récit mursal {cite:muwatta-maruf-1997} [[passage/muwatta-5-895|Muwatta 895]].

## Le sens
Dans ce récit, le songe peut constituer une preuve collective pour les temps d'adoration ; la parole du Prophète selon laquelle les songes se sont accordés sur le dernier tiers est un signe qu'il s'agit de la nuit promise {cite:muwatta-maruf-1997}.
