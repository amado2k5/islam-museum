## Le récit
Muslim rapporte, d’après Abu Hurayra, que le Prophète a dit : « Lorsque le Ramadan arrive, les portes du Paradis s’ouvrent, les portes de l’Enfer se ferment et les shayatin sont enchaînés » {cite:sahih-muslim} [[passage/muslim-1079|Muslim 1079]]. Dans le Muwatta de Malik, on rapporte, d’après Abu Suhayl ibn Malik, d’après son père, d’après Abu Hurayra, le hadith suivant : « Lorsque le Ramadan arrive, les portes du Paradis s’ouvrent, les portes de l’Enfer se ferment et les shayatin sont enchaînés » — l’éditeur note qu’Ibn Abd al-Barr l’a rapporté marfu’ d’après Abu Suhayl {cite:muwatta-maruf-1997} [[passage/muwatta-4-862|Muwatta 862]].

## La signification
Dans ce hadith, le Ramadan est présenté comme la période durant laquelle les shayatin sont enchaînés, les portes de l’Enfer se ferment et les portes du Paradis s’ouvrent — une image cosmique illustrant la vertu du jeûne {cite:sahih-muslim}.

## Notes
Le rapport de Muslim est marfu’, tandis que celui du Muwatta est mauquf, avec des versions marfu’ mentionnées ; le « Jinn & Devils Browser » présente les deux dans la section des démons {cite:sahih-muslim} {cite:muwatta-maruf-1997}.
