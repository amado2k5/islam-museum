## Résumé
Le premier hadith dans le chapitre sur le jeûne les jours de Mina. Malik transmet d'Abu al-Nadr, client d'Umar ibn Ubaydallah, de Sulayman ibn Yasar, que le Messager de Dieu interdisait le jeûne les jours de Mina. L'éditeur note que la version relayée dans le Muwatta est celle conservée de Malik ; que Sufyan al-Thawri l'a reliée via Salim Abu al-Nadr et Abdullah ibn Abi Bakr depuis Sulayman ibn Yasar depuis Abdullah ibn Hudhafa al-Sahmi ; qu'Ibn Maʿin l'appelait relayée ; et qu'Ibn Abd al-Barr la considérait comme reliée par d'autres voies. {cite:muwatta-maruf-1997 p.504}
