**Commentaire sur le verset 112 (p. 24)**

Al-Tabari rapporte que ceci est le récit divin des conseils que les chefs du peuple de Pharaon lui donnèrent : envoyer des huissiers dans les villes pour rassembler tous les sorciers compétents. Un élément est omis dans le texte, mais le sens apparent du propos le rend superflu : « il envoya donc des huissiers dans les villes pour rassembler les sorciers ». {cite:tafsir-tabari-shakir-v13 p. 24}
