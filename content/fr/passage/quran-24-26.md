## Dans le commentaire d'al-Tabari

Le verset « Les femmes perverses sont pour les hommes pervers, et les hommes pervers sont pour les femmes perverses. Les femmes vertueuses sont pour les hommes vertueux, et les hommes vertueux sont pour les femmes vertueuses. Ceux-là sont innocents de leurs paroles. Pour eux sont le pardon et une généreuse provision. » a fait l'objet de diverses interprétations par les savants. Certains affirment qu'il signifie : les paroles malveillantes sont pour les hommes pervers, et les hommes pervers sont pour les paroles malveillantes ; les paroles bienveillantes sont pour les gens vertueux, et les gens vertueux sont pour les paroles bienveillantes. Le passage cite également des interprétations attribuées à Ibn Abbas et à Mujahid.
