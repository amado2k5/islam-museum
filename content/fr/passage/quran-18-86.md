## Dans le commentaire d'al-Tabari

Son verset : « Jusqu'à ce que, lorsqu'il atteignit le coucher du soleil, il le trouva se coucher dans une source boueuse, et il trouva près de là un peuple. Nous avons dit : « Ô Dhul-Qarnayn, soit tu les châties, soit tu leur inspires la vertu » est interprété comme suit : « Jusqu'à ce que, lorsque Dhul-Qarnayn atteignit le coucher du soleil, il le trouva se coucher dans une source boueuse. » Les récitateurs ont divergé dans leur interprétation de ce passage. Certains récitateurs de Médine et de Bassora l'ont lu ainsi : « dans une source boueuse », c'est-à-dire qu'il se couche dans une source d'eau boueuse. Un groupe de récitateurs de Médine l'a lu ainsi : « dans une source chaude », c'est-à-dire qu'il se couche dans une source d'eau chaude. La lecture courante du Coran est : « dans une source chaude », c'est-à-dire qu'il se couche dans une source chaude. Les savants exégètes ont divergé dans leur compréhension de ce passage, tout comme les récitateurs ont divergé dans leurs interprétations. Le passage cite des déclarations d'Ibn Abbas, Mujahid, Qatadah, Ikrimah, Ibn Jurayj et Ata.
