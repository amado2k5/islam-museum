## Résumé
Verset 60 de [[passage/quran-21|la sourate al-Anbiya]], une sourate mecquoise. {cite:tanzil-quran}

## Place dans le musée
Il s'agit du verset 60 sur 112 dans la sourate. Le texte est conservé dans le mushaf Tanzil et n'est pas reproduit ici.

## Dans le commentaire d'al-Tabari

Al-Tabari considère le verset inclus dans les versets 59 à 61 comme une seule section. Il interprète les paroles : « Ils dirent : “Nous avons entendu un jeune homme les mentionner ; il s’appelle Abraham” » comme suit : Ceux qui l’ont entendu dire : « Par Dieu, je comploterai certainement contre vos idoles après votre retraite », dirent : « Nous avons entendu un jeune homme les mentionner de manière péjorative ; il s’appelle Abraham. » Il dit également : Hajjaj m’a rapporté, d’après Ibn Jurayj : « Ils dirent : “Nous avons entendu un jeune homme les mentionner.” » Ibn Jurayj dit : Il les mentionne, il les critique. D’après Ibn Ishaq, concernant sa déclaration : « Nous avons entendu un jeune homme les mentionner, nommé Ibrahim », nous l’avons entendu les injurier, les critiquer et se moquer d’eux. Nous n’avons entendu personne d’autre dire cela, et nous pensons que c’est lui qui leur a dit cela. Le passage cite également des déclarations de Qatadah et d’Ibn Ishaq.
