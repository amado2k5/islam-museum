## Résumé
Malik dit : la pratique convenue entre nous dans le cas d'un homme qui achète un esclave puis découvre un défaut pour lequel il peut le rendre, et un autre défaut lui est apparu entre les mains de l'acheteur : si le défaut survenu est dommageable, comme l'amputation, la cécité ou d'autres défauts dommageables, alors l'acheteur choisit la meilleure des deux options. S'il le souhaite, le montant du défaut qui était dans l'esclave le jour de l'achat est déduit du prix ; s'il le souhaite, il peut payer le montant du défaut acquis par l'esclave entre ses mains puis le rendre. Si l'esclave meurt entre les mains de l'acheteur, l'esclave est évalué selon le défaut qu'il avait le jour de l'achat, et le prix est déterminé : si la valeur de l'esclave le jour de l'achat, sans défaut, était de cent dinars, et sa valeur le jour de l'achat avec le défaut était de quatre-vingts dinars, alors la différence entre les deux valeurs est déduite de l'acheteur. {cite:muwatta-maruf-1997 p.135}
