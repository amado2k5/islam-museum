## Résumé
Verset 28 de [[passage/quran-23|la sourate al-Mu'minun]], une sourate mecquoise. {cite:tanzil-quran}

## Place dans le musée
Il s'agit du verset 28 sur 118 dans la sourate. Le texte est conservé dans le mushaf Tanzil et n'est pas reproduit ici.

## Dans le commentaire d'al-Tabari

Sa déclaration : « Lorsque vous serez installés sur le navire avec ceux qui vous accompagnent, dites : “Louange à Allah qui nous a sauvés des injustes” », signifie que lorsqu’Il, exalté soit-Il, dit : « Lorsque vous serez installés sur le navire avec ceux qui vous accompagnent », alors, lorsque vous et les membres de votre famille que vous avez emmenés avec vous serez installés sur le navire, à bord, « dites : “Louange à Allah qui nous a sauvés des injustes” », c’est-à-dire des polythéistes.
