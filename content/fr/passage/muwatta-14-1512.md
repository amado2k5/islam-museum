## Résumé
Un rapport que Malik transmet de Humayd al-Tawil d'Anas ibn Malik, qui disait autrefois : pour une vierge, sept nuits ; pour une femme déjà mariée, trois. Malik dit que c'est la pratique parmi nous. L'éditeur note que le hadith est élevé dans le Sahihayn par Abu Qilaba à partir d'Anas. {cite:muwatta-maruf-1997 p.35}
