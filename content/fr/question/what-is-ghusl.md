## Réponse courte
Le Ghusl est la purification majeure avec de l'eau, le lavage de tout le corps après une impureté majeure, les rapports sexuels, les menstruations et les saignements post-partum. C'est une condition pour une prière valide pour quelqu'un dans un état d'impureté majeure.

## Réponse détaillée
Le Coran rendit le ghusl obligatoire après une impureté majeure dans la sourate al-Ma'ida {cite:tanzil-quran}.
L'entrée sur [[practice/ghusl-al-janaba|le ghusl]] en expose la manière et ce qui l'exige ; elle est liée à l'[[practice/wudu|ablation]] dans les chapitres sur la purification.
