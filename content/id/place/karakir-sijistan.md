## Ringkasan
Karakar adalah rumah api di Sijistan, yang direbut oleh Bahman ibn Isfandiyar ibn Yastasuf menurut apa yang diceritakan al-Mas'udi dalam laporan rumah api di antara bangsa Persia. {cite:muruj-al-dhahab p. 549}

## Detail
Dalam bab tentang laporan rumah pemadam kebakaran di antara orang Persia dari padang rumput emas, Al-Mas'udi mencantumkan lokasi dan laporan kebakaran: Di antaranya adalah sebuah rumah api di Sijistan yang disebut Karakar, yang diambil oleh Bahman ibn Isfandiyar ibn Yastasif; rumah lain di Tiongkok di luar Al-Barkind; dan sebuah rumah api di kota Arjan di tanah Persia yang diambil pada masa Bahrasif. {cite:muruj-al-dhahab p. 549}

Al-Mas'udi juga menyebutkan Rumah Api di Istakhr Faris, yang dihormati oleh para Majus, dan perlindungan putri Bahman ibn Isfandiyar telah mengambilnya dan mengubahnya menjadi rumah api, lalu api itu dipindahkan dan dihancurkan. {cite:muruj-al-dhahab p. 549} Dalam catatan ini, Krakar adalah tempat pemujaan api kuno di Sijistan, yang Al-Mas'udi atribusikan kepada seorang raja raja Persia pertama. {cite:muruj-al-dhahab p. 549}
