## Ringkasan
Sebuah lembah luas yang terletak di satu panggung di utara [[place/mecca|Mekah]] (sekarang dikenal sebagai Wadi Fatimah); pasukan penakluk mendarat di sana dengan sepuluh ribu pejuang dan menyalakan sepuluh ribu api dalam situasi yang menakutkan Quraysh, di mana [[person/abu-sufyan-ibn-harb|Abu Sufyan menyatakan]] pertobatannya {cite:ibn-hisham-saqqa 4/42-46}.

## Dalam biografi Ibn Hisham
Ibn Ishaq menceritakan bahwa Nabi mendarat di Mar Dhahran pada malam hari, memerintahkan para sahabatnya untuk menyalakan api masing-masing orang, dan sepuluh ribu api menyalakan gunung dan cakrawala {cite:ibn-hisham-saqqa 4/42}. Dalam upacara ini, Abbas ibn Abd al-Muttalib membawa Abu Sufyan dengan keledai putih milik Nabi, dan suku-suku memamerkan senjata mereka di celah lembah dekat ujung gunung {cite:ibn-hisham-saqqa 4/44-47}.

## Untuk pengunjung muda
Lembah besar dekat Mekah menyalakan sepuluh ribu api oleh pasukan pada malam hari, membuat pemandangan itu memukau dan menakutkan bagi siapa pun yang melihat dari kejauhan, membuat para pemimpin Mekah menyadari bahwa perlawanan sia-sia.
