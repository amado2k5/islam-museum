## Ringkasan
Di Jumada al-Akhirah pada tahun 654 H, kebakaran besar terjadi di Al-Harrah dekat [[place/medina|Madinah]]. Al-Suyuti menceritakan deskripsinya dari Abu Shama, dan Ibn al-Imad menyebutkan laporan serupa dalam "Shadharat al-Dhahab." {cite:tarikh-khulafa-minhaj-1434 p. 709-710} {cite:shadharat-dhahab p. 271-272}

## Deskripsi Abi Shama
Al-Suyuti mengirimkan surat dari Abu Shama yang diterimanya dari Madinah. Disebutkan bahwa gemuruh besar diikuti gempa bumi terjadi pada malam Rabu, tanggal tiga Jumada al-Akhirah, dan berlanjut hingga tanggal lima bulan itu. Kemudian api menyala di Al-Harrah dekat Quraiza, terlihat dari rumah-rumah di kota. Wadi mengalir dari sana ke Wadi Shaza, percikan api seperti istana beterbangan, dan cahayanya terlihat dari Mekah. Orang-orang berkumpul di makam bangsawan, memohon pengampunan dan pertobatan, dan ini berlangsung lebih dari sebulan. {cite:tarikh-khulafa-minhaj-1434 p. 709-710}

## Ucapan Al-Dhahabi
Al-Suyuti mengutip Al-Dhahabi bahwa masalah api ini adalah mutawatir. Ia menemukan keaslian hadits di dalamnya: "Jam tidak akan ditetapkan sampai api keluar dari tanah Hijaz untuk menerangi leher unta di Bosra," dan menyebutkan bahwa lebih dari satu orang di Bosra melihat leher unta dalam cahaya mereka. {cite:tarikh-khulafa-minhaj-1434 p. 709-710}

## Novel 'Fragmen Emas'
Ibn al-Imad menyebutkan bahwa api itu berlangsung selama beberapa hari, atau beberapa orang mengatakan tiga bulan, dan para wanita di kota menangis di bawah cahayanya. Api itu muncul dari lembah Ahilin di al-Harrah timur, dan bergerak ke utara, memakan batu dan gunung tetapi tidak pohon. Diceritakan bahwa pemilik kota, Munif ibn Shabha, mengirim dua orang untuk membawa kabar tentang kebakaran itu. Disebutkan bahwa api itu memblokir Wadi Shadha dengan batu cor, sehingga air terperangkap di belakangnya, lalu air memecahkannya pada tahun 690 H. {cite:shadharat-dhahab p. 271-272}

## Sejarah
Jumada al-Akhirah 654 H, dan padanan Gregorian (sekitar 1256 M) adalah transformasi turunan. {cite:tarikh-khulafa-minhaj-1434 p. 710}
