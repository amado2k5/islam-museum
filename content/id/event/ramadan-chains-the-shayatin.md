## Cerita
Muslim menceritakan dari Abu Huraira bahwa Nabi berkata: Ketika Ramadan tiba, gerbang surga akan dibuka, gerbang api neraka akan tertutup, dan para iblis akan dirantai {cite:sahih-muslim} [[passage/muslim-1079|Muslim 1079]]. Dalam Al-Muwatta, Malik menceritakan dari Abu Suhail ibn Malik dari ayahnya dari Abu Huraira, dengan catatan tertunda tentang ucapannya: Ketika Ramadan masuk, gerbang surga dibuka, gerbang api neraka tertutup, dan iblis dirantai. Verifier menyebutkan bahwa Ibn Abd al-Barr menceritakannya sebagai hadis marfu' dari Abu Suhayl {cite:muwatta-maruf-1997} [[passage/muwatta-4-862|Al-Muwatta' 862]].

## Makna
Dalam hadits ini, Ramadan adalah musim di mana iblis dirantai, gerbang api neraka ditutup, dan gerbang Surga dibuka—gambaran kosmik dari kebajikan puasa {cite:sahih-muslim}.

## Catatan
Narasi Muslim adalah marfu'ah, dan narasi Al-Muwatta' adalah mawqoof dengan rantai marfu'ah; keduanya disajikan oleh Iblis dan Jin Browser dalam bagian Iblis {cite:sahih-muslim} {cite:muwatta-maruf-1997}.
