## Ringkasan
Menurut Sunni, Neraka adalah tempat tinggal penderitaan yang awalnya diciptakan di akhirat — "Surga dan Neraka adalah dua entitas ciptaan yang tidak akan pernah binasa atau binasa" {cite:aqida-tahawiyya §106-107}.

## Dalam doktrin
Komentar Al-Tahawiyya menyebutkan bahwa orang-orang yang berdosa besar dari bangsa Muhammad tidak akan tinggal di dalam Api jika mereka mati sebagai seorang monoteis {cite:sharh-tahawiyya-ibn-abi-al-izz §89}. Kredo telah ditegaskan bahwa Allah menciptakan Api sebelum penciptaan dan umatnya, sehingga siapa pun di antara mereka yang berkehendakan akan masuk ke dalam Api dengan keadilan dari-Nya {cite:aqida-tahawiyya §107}.

## Tentang program Shaarawi "Di Alam Hadis Suci"
Episode keempat belas dari [[work/fi-rihab-al-hadith-al-qudsiyyah|"Di Alam Hadis Suci" menjelaskan]] hadits api yang mengeluh kepada Tuhannya, bahwa sebagian api saling memakan sehingga diizinkan bernapas di musim dingin dan musim panas. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:00:00} Pembawa acara menampilkan matahari sebagai model api mini, menghubungkan bahan bakar nuklirnya dengan ayat yang membuat batu sebagai bahan bakar, menyajikan ini sebagai pendapat program. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:01:30} {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:27:30}

Al-Shaarawi [[person/muhammad-mutawalli-al-shaarawi|mengatakan]] bahwa keluhan tentang Api menunjukkan bahwa sesuatu telah menghalangi misinya, dan setiap makhluk telah mengetahui misinya sejak penciptaannya. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:12:30} Ia percaya bahwa Api adalah makhluk yang menerima hukuman, dan bahwa Api mengeluh terlebih dahulu karena mencegah bahaya lebih diutamakan daripada membawa manfaat, sama seperti tangan bergerak melindungi batu sebelum menangkap apel. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:19:30} {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:20:00} Ia mengatakan bahwa Allah menjaga kebijaksanaan-Nya dalam menunda dan rahmat-Nya dengan izin Api untuk jiwa-jiwa, mengingatkan orang-orang akan panasnya musim panas bersamanya. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:21:00} Dicatat bahwa Tuhan tidak hanya berkata tentang Api, "Jika Kami berkehendak, Kami akan memadamkannya," tetapi menjadikannya pengingat dan manfaat bagi para pelancong. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:24:30}

Berasal dari ini bahwa jika api tidak menemukan apa yang dimakannya, api akan memakan dirinya sendiri. Ia mengatakan bahwa setiap kejahatan datang setelah dihukum kecuali kebencian, dan hukumannya datang sebelum api; api membakar hati pemiliknya sebelum sesuatu terjadi. {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:25:00} {cite:assabile-muhammad-metwally-al-shaarawy fi-rihab-al-hadith-al-qudsiyyah/ep14 00:26:30}

## Dalam Tafsir al-Tabari
Dalam penafsiran 'Maka takutlah Api, yang bahan bakarnya adalah manusia dan batu,' Al-Tabari menceritakan dari Ibn Mas'ud bahwa batu terbuat dari belerang yang Allah ciptakan di surga terendah dan dipersiapkan untuk orang kafir. Ibn Abbas dan beberapa sahabat menceritakan bahwa itu adalah belerang hitam dalam Api, dan dari Amr ibn Dinar bahwa itu lebih keras dan lebih besar. Lihat [[passage/quran-2-24|juga ayat 24]]. {cite:tafsir-tabari-shakir-v01 p. 380} {cite:tafsir-tabari-shakir-v01 p. 382}
