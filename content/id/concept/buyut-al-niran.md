## Ringkasan
Orang pertama yang menarik rumah api dari raja-raja Persia adalah Al-Mas'udi Afridun. Ia menemukan api yang dihormati oleh rakyatnya, yang memberitahunya bahwa api itu adalah perantara antara Tuhan dan ciptaan-Nya serta para dewa Nuri. Mereka menetapkan tingkat cahaya dan membedakan antara sifat api dan cahaya. Ia memerintahkan sebagian api dibawa ke Khorasan, sehingga ia membangun rumah untuknya di Tus dan satu lagi di Bukhara yang disebut Bard Surah; sebuah rumah di Sijistan dibangun oleh Bahman ibn Isfandiyar; sebuah rumah di Balshiz dan Ran yang berhala-berhalanya dibawa keluar oleh Anushirwan, dan dikatakan memindahkan apinya ke kolam; Kusja, dibangun oleh Kaykhosrow; Jurish, dikatakan ditinggalkan oleh Alexander; konon Alexander meninggalkannya dan tidak memadamkannya; Najdah dibangun oleh Siyush ibn Kaykawus di Tiongkok timur di luar Al-Barkand; dan sebuah rumah di Arjan, diambil pada masa Bahrasif. Mereka menjelaskan daya tarik hewan terhadap api seperti tempat tidur di malam hari dan paus yang pergi ke pelana perahu, seperti yang diburu di Basra {cite:muruj-al-dhahab p.549-550}.
