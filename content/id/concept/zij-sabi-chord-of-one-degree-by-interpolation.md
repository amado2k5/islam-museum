## Ringkasan
Al-Battani menyatakan bahwa beberapa string, string dari satu bagian dan perkaliannya, tidak dapat diekstrak dengan perhitungan menggunakan metode pembuktian seperti string lain, tetapi ia tahu melalui bukti bahwa rasio string busur minor terhadap busurnya lebih besar daripada rasio string busur mayor terhadap busurnya. Jadi ia menggunakan bagian, setengah, setengah, dan seperempat yang diketahui, lalu mengambil string tiga perempat dan menambahkan satu pertiga untuk menjadikannya string dari satu bagian. {cite:zij-sabi-nallino-byblion p.18}.

## Apa yang tidak dapat dibuktikan
Ia mengatakan bahwa string yang tidak diketahui secara bukti adalah pemotongan satu bagian dan perkaliannya, seperti dua, empat, dan delapan, tidak menghasilkan perhitungan melalui jalur pembuktian seperti string dan string lainnya, tetapi ia tahu melalui bukti bahwa rasio string busur minor terhadap busurnya lebih besar daripada rasio string busur mayor terhadap busurnya. Dengan demikian, batas yang tidak dapat dicapai dengan bukti murni dibatasi antara dua istilah yang diketahui. {cite:zij-sabi-nallino-byblion p.18}.

## Pendekatan dua pertiga dari bagian setengah
Disebutkan bahwa string bagian dan setengah serta string setengah dan quarter diketahui melalui pembuktian, dan apa yang diperoleh dari dua pertiga string bagian dan setengah sama dengan apa yang diperoleh dari string setengah dan seperempat jika ditambahkan sama dengan sepertiga, dan tidak ada perbedaan antara keduanya yang dirasakan dan tidak menyebabkan kerugian dalam perhitungan. Jika string tiga perempat diambil dan ditambahkan sama dengan sepertiga, konjungsi menjadi string dari satu bagian. {cite:zij-sabi-nallino-byblion p.18}.

## Dampaknya pada tabel
Kesimpulan ini menyimpulkan bahwa setelah string dari satu bagian diketahui di sisi ini, semua string dari bagian setengah lingkaran juga menjadi diketahui. Dengan demikian, seluruh tabel didasarkan pada apa yang muncul dari string dan pada pendekatan deklarasi tunggal ini, yang membuat pembacaan tabel menjadi jelas. {cite:zij-sabi-nallino-byblion p.18}.
