## Ringkasan
Ayat 36 [[passage/quran-35|Surah Fatir]], yang merupakan surah Mekah. {cite:tanzil-quran}

## Posisinya
Lokasinya: Ayat 36 dari 45 dalam surat. Teks ini disimpan dari Mushaf Tazil al-Mujjad dan tidak ditulis ulang di sini.

## Dalam Tafsir al-Tabari

Al-Tabari membaca ayat dalam ayat 36 sampai 37 sebagai satu bagian. Ia menafsirkan firman-Nya, “Dan orang-orang kafir akan mendapat api neraka. Mereka tidak akan ditakdirkan untuk mati, dan azabnya tidak akan diringankan bagi mereka. Demikianlah Kami membalas setiap orang kafir”: “Dan orang-orang yang kafir” kepada Allah dan Rasul-Nya, “akan mendapat api neraka.” Ia berkata: Mereka akan mendapat api neraka, tinggal di dalamnya selama-lamanya, tanpa bagian di surga atau kebahagiaannya. Adapun Qatadah, “Mereka akan mendapat api neraka. Mereka tidak akan ditakdirkan untuk mati,” karena jika mereka mati, mereka akan mendapat kelegaan. “Dan azab mereka tidak akan diringankan.” Ini berarti bahwa azab api neraka tidak akan dikurangi bagi mereka dengan menyebabkan kematian mereka, sebagaimana diriwayatkan dari Qatadah, dari Abu al-Sawda’, yang berkata: “Orang-orang miskin di neraka tidak mati; jika mereka mati, mereka akan mendapat kelegaan.” Bagian tersebut juga memuat pernyataan yang dinisbahkan kepada Mujahid dan Qatadah.
