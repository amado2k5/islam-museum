# 66. Sport Browser — Sports and Competitions in Islam

**متصفح الفروسية والسباحة والرماية وجميع رياضات ومنافسات المسلمون** — a browser over the one graph
listing everything the museum's sources mention about sport and contest: horsemanship, swimming
and archery (the training trio), wrestling and strength, races and wagered contests, spear-play,
ball and board games, hunting as field sport and the modern game — in the Qur'an, the Sunnah, the
seerah, Companion and Tabi'in reports and every harvested book, present and future.

Original founder requirement (verbatim, 2026): «متصفح الفروسية والسباحة والرماية وجميع رياضات
ومنافسات المسلمون — where it should list all the mentioned and written that are in quran, see-rah,
sunna, tabi'een stories, quotes, mentioned and written in books that were harvested and any future
harvested book … should be viewable here. add a box for it on landing page and in navigation
menus. make sure this is done end to end and full detailed process and make it ready for
production». Scope approved: everything including modern; a dedicated `sport` class; URL `رياضة
/sport/`. Acceptance spec: `docs/engineering/58-sport-browser-requirements.md`.

## Architecture (the established browser pattern)

- `scripts/sport.ts` — shared guarded-lexicon detector: eight families (khayl horses/furusiyya,
  ramy archery, sibaha swimming, sira wrestling/strength, sabq races/wagers, laib play/games, sayd
  hunting, riyada modern sport) with context guards on ambiguous words and id-based false-positive
  exclusions, so a book harvested later brings its sport mentions automatically.
- `site/src/lib/sport.ts` — shared reader: passages by corpus (quran/sunnah/seerah/books), tagged
  records in `curated`, `sport` class records as the named-sports shelf, athletes from `person.sports`.
- `site/src/pages/[lang]/sport/[...page].astro` — trilingual landing with counts, the signature
  view `sig/SportFields.astro` (the contest ground: a ruled strip per family, a disc per corpus
  sized by count), the named sports, athletes on record, corpus sections, client-side filter
  (`scripts/sport-filter.ts`, progressive enhancement).
- `/api/v1/sport.json` in `scripts/export-api.ts` (section, topics, signals per passage).
- Explore key `sport` in `site/src/lib/nav.ts` (conduct group), landing card in `Landing.astro`,
  i18n blocks in `i18n/{ar,en,ur}.yaml` (explore entry + `sport:` page block).
- New class `sport`: `schema/sport.schema.json` (generated by `scripts/gen-schema.ts`), `CLASSES`
  in `scripts/lib.ts`, `kind` enum (mounted/target/water/combat/racing/ball-game/board-game/
  strength/hunt/modern-team/modern-individual), `era`, `status_today`, `furusiyya`.

## Content wave 1

- 17 `sport` records: furusiyya, ramy, sibaha, musaraa, sibaq-al-adyam, sibaq-al-khayl,
  sibaq-alibil, laib-al-hirab, mubaraza, suljan, kura, ishalat-al-hajar, sayd, shatranj, nard,
  okmanzil, football — each trilingual (label, summary, prose ar/en/ur), sourced to defined
  source records, `status.review`, `provenance`.
- 5 `event` records for the famous contests: the two Aisha races, the Prophet's bout with Rukana,
  the Abyssinians' spear-play in the mosque, the horse race at the musalla.
- 10 existing records tagged `sport-browser` in place (al-rimaya, al-musara-a, sabq-in-islam,
  nakhwa-chivalry, named-exercises-of-the-canon, rahan-fiqh, nard, al-furusiyya,
  kitab-al-furusiyya-wal-manasib-al-harbiyya, sahn-furusiyya) — reused, not duplicated.

## Rules observed

Qur'an text never typed — referenced via `passage/quran-*` records only; no honorifics; Arabic
parentheses isolated; docent voice, no rulings; Sunni frame default; every record cites defined
sources; draft/provenance honest.

## Next waves

Deeper Companion/Tabi'in contest reports (Ali–Uthman wrestling accounts where sourced); more
modern athletes as `person.sports` blocks land; detector tuning from the signals API field.
