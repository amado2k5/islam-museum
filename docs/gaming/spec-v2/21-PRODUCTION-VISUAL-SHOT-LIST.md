# Production visual capture and art-direction briefs

These are 60 distinct required production reference/capture targets, not 60 existing images. Use the bundled 27 image/diagram assets for initial direction. Produce the following from real playable scenes as each game matures; before a scene exists, a new concept may be commissioned or generated only as clearly labelled inspiration. Do not make external AI/image API access or new purchases a dependency. Each capture must record commit, scene seed, camera, resolution, preset, browser, GPU, content IDs, source and asset rights; retain clean frame and HUD variant when useful. Prioritize motion, legibility, composition and historical review over still-frame beauty. Capture 1440p or 4K on actual supported hardware where available, with measured performance, not upscaled crops.
