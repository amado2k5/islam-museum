## What is and is not supplied
This is a production blueprint, not game code. Concept art is illustrative, including AI-generated architecture, UI labels and numbers that may be inaccurate. The package includes existing V1 artwork and new annotated/vector design boards; no image is a real gameplay screenshot. Do not use these as historical evidence or blindly import them as production assets. External examples are creator-reported unless separately verified. No live repository audit, real GPU benchmarks, account permissions or hosting changes are performed by this specification. Current policies and browser releases must be verified at implementation and submission. No new spend, contracts or production merges are authorized merely by reading the package.
