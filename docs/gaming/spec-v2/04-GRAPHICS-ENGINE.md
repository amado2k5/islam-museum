# Graphics engineering specification
## Requirements and choice
WebGPU-first premium rendering, compare Three.js WebGPURenderer/TSL versus Babylon.js on the same reference scenes. Pin one main 3D stack after benchmark; isolate renderer behind small resource/scene contracts, not a universal lowest-common-denominator wrapper. Use 2D/DOM for puzzles and menus when better. Verify recent stable Chrome and Edge release channels; Chrome 158.0.8127.88/.89 was the general desktop stable update on 23 November 2026; Chrome 159.0.8154.33/.34 entered limited early stable rollout on 24 November ([official release archive](https://chromereleases.googleblog.com/2026/11/), [23 Nov desktop update](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop_01734282054.html)). Verify current Edge stable from [Microsoft release notes](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-relnote-stable-channel) before setting the release support matrix; do not freeze an untested major version. Secure context, requestAdapter, requestDevice with required limits/features; test tiny pipeline and representative benchmark; check storage, workers, audio and input. Optional timestamp queries and other features negotiated per adapter. No browser flags or UA-only checks; unsupported screen tells exact tested versions, actual failed capability and practical remedy, with captured footage and return link. Do not claim GPU VRAM from unreliable heuristics.

| Tier | Design target (not tested minimum) | Goal |
|---|---|---|
| High | 16 GB RAM, 8 GB VRAM class discrete GPU or equivalent | 1440p, 60fps |
| Ultra | 32 GB RAM, 12–16 GB VRAM class or equivalent | 4K, 60fps where measured |
| Cinematic | tested high-end GPU, optional reduced interaction rate | 4K, 30+fps |
Use real reference machines including Apple silicon unified memory if available; record device class rather than comparing memory directly. Targets can be revised transparently after spikes. Settings: render scale, shadows, draw distance, vegetation, reflections, effects, AA, FOV, FPS cap, motion blur, depth of field, reduced motion, UI scale; high fidelity stays default on proven capable machines. Resolution scaling does not alter simulation. Persistent quality profile per game.

## Rendering pipeline
Stream cells by camera/frustum and movement prediction. Instanced modular assets, HLOD impostors, meshlet/indirect culling only if selected API and engine support it; compute particles and foliage with bounded buffers. PBR linear workflow, correct color spaces, physically inspired sun/sky, baked lighting where appropriate, cascaded shadows, AO, reflection probes, selective volumetric haze, tone mapping and color grade. Evaluate TAA/upscaling with moving objects, thin geometry, water and text; avoid ghosting and excessive bloom. Use glTF 2.0, meshopt/Draco and KTX2/Basis after measuring decode and transfer; shader prewarming in loading phase; texture residency and eviction; async staging and pool reuse. Never allocate buffers each frame unnecessarily. Geometry/material variation by era and region, not random mixing of architecture. Visible crowd proxies use LOD and animation batching; actual simulation uses aggregate data plus representative agents. Rendered water/cloth/particles are visual effects separate from rules.

## Acceptance and budgets
Initial spike budgets (tune against GPU, never advertise as achieved): city district 500–1500 visible buildings, 200–800 visible agent proxies; streamed landscape 1 km² active cells with distant scenery; workshop 100 moving components; curator 30 detailed objects in gallery; architecture 1000 modular pieces. Capture close and distant view, day/night, movement, dense UI. Measure p95 frame time <=16.7ms target for 60fps, <=33.3ms cinematic; disclose misses, resolution, effects and long frames. Profile GPU and CPU separately; GPU timestamps optional. Observe memory and GPU allocations; test 60 min repeated scene switching, 30 min soak, tab suspension, resize, device loss and restore checkpoint. CI software renderer catches regressions, not real performance. Add visual snapshots with perceptual tolerance and manual comparison. Prove no leak after 20 scene cycles and no permanent GPU device loss save corruption. Never report a fake benchmark. Build reference-scene capture command and overlay with opt-in export, no hardware fingerprinting collection.
