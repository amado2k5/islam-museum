## Setup
Open actual repository and verify clean status/branch ownership. Update Claude Code only through official mechanism if needed. Verify `claude --help` and actual model/effort selector, then choose Fable 5.2 and `high`. Interactive `/model` and `/effort high` when supported; switch `/effort xhigh` for specific risk. Model selector may require actual model ID or availability. If supported by local CLI, example `claude --model claude-fable-5-2 --effort high`; otherwise use picker and `/effort`. Check active model/effort via status/config; no bypass permissions flags. Brief Plan Mode only if useful for discovery, then return to editing/execution; Plan-only cannot deliver code. Normal permission mode with scoped approvals for tools, not unrestricted auto-approve. Local GPU/browser required for actual render benchmarks; cloud agent may do headless CI but cannot substitute GPU tests. Use Playwright and real Chrome/Edge separately. No runtime access to secrets beyond necessary approved environment.

Give concise meaningful progress updates. Continue authorized work; stop only for real blockers/approval boundaries. Report errors honestly, never lower acceptance bar.
