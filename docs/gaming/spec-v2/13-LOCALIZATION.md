# Seven languages, accessibility and international UX
Read actual locale registry, translations, route patterns, fonts, pluralization and editorial conventions; use all seven real languages. Do not assume English/Arabic/Urdu are the only or exact list. Localize portal, navigation, settings, onboarding, campaign, clues, hints, result, share card, unsupported message, developer docs and relevant source links. Stable content IDs independent of translation. Separate UI strings from narrative/source labels; use ICU-like messages and locale number/date formats; no concatenated sentences, reversed strings or text baked into assets. Translation completeness lint and explicit approved fallback; never silently claim full localization with missing content. RTL menus mirror intentionally, maps/timelines/physical instruments/control axes remain semantically correct; mixed script via bidi isolation. Test shaping and diacritics at actual fonts. Subtitle/caption layout, dynamic text expansion, wrapping and UI zoom. Preserve proper names and historical terminology consistently.

Web interface WCAG 2.2 AA target: visible focus, keyboard access, labels, contrast, screen reader status, skip links, no focus trap except dismissible dialogs, remappable inputs, reduced motion, captions, mute and volume, non-color-only signals. Canvas content has semantic DOM overlay or alternative navigation for essential tasks; document unavoidable game-specific limitations and test equivalent actions. No flashing hazard, nausea-inducing forced camera, mandatory audio cues or tiny HUD. Support keyboard/mouse and gamepad where appropriate; touch for puzzle games when feasible, not a requirement to degrade desktop graphics. Test 7 locales × key screens × RTL/LTR × UI scale × supported browsers; include screenshot and functional assertions. Native review required for high-stakes history and language accuracy; machine-translated text is a candidate until reviewed. See [WCAG](https://www.w3.org/TR/WCAG22/) and [W3C internationalization](https://www.w3.org/International/).
