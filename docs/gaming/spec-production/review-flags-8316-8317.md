**What was run** (Blender 5.3.0, 26 November 2026, on the developer's machine, with the branch brought up to `main`):

- The corrected script was run twice and `main`'s untouched script once, each exporting the full palace. In all three every part's positions, normals, colours, texture coordinates and tangents are byte for byte the same, 214,166 triangles in 19 parts. What differs is the order in which the triangles of three or four parts are listed, and it differs between the two runs of the same script as much as between the corrected script and `main`'s: the exporter does not list them the same way twice (the second agent measured the same). **So the corrections change nothing of the model.** Whole-file checksums therefore cannot be used to tell one export from another, and are not offered as proof.
- Against the file that was judged in the game (made before the second agent's change that added the low-detail versions): 18 of the 19 parts are identical in positions and colours; the marble part has the same triangles and two more vertices, 34,589 against 34,587. `main`'s untouched script gives the same 34,589, so the difference came in with that earlier change and not with these corrections. It is two vertices in 407,717 and was not looked into further.
- The first run stopped at the picture step with an error: the correction for row 4 used Blender's own module in a script that had not imported it. That was a fault in the correction, found only by running it, and is mended. The second run rendered the four pictures and the ground is earth-coloured. The committed pictures are still the earlier ones, as row 4 says.

**Checked and found sound by the same review:** the founder's third decision is kept word for word (the only differences from his file are the note above it and the fence round it); `plan.json` parses and the counts agree across the pages; every relative link resolves; no absolute path of the machine and no media beyond five small evidence pictures were committed; the arch, roof and frame arithmetic in the scripts; the script is deterministic; every mention of the Alhambra is a disclaimer.

**What this does not settle.** An equivalent review is not the same review: the reviewer's five may name something these eight do not. Until they are read, that is open, and this page says so at its head.
