# The Lantern: release evidence, 28 November 2026

**Decision.** On 28 November 2026 the founder asked to finish one game at a time, then: "yes go on to lantern finish it completely". It is the last of the four daily games. Its status is `production` in [`release-status.json`](../../spec-production/release-status.json) and `released` in `gaming/games/registry.json`, on his word.

**What was not done, and still is not.** The founder released the game without these:
- **A playtest.** No person outside the agents has played it.
- **Native readers.** No native speaker has read the Urdu, French, Spanish, Turkish or Indonesian strings or names. They are machine work.
- **Real phones.** No real phone was used: the phone checks are an emulated 375×812 screen.

## Changed for this release

1. **A lighter first visit.** The game now loads a names file holding only its own phrases (`phrase-labels.v1.<lang>.json`). Compressed, that is 30 to 40 KB a language, where the whole label file was 140 to 204 KB.
   - The pack builder writes the file.
   - A test holds it equal to the label file for those phrases.
   - Practice rounds draw from the same phrases, so nothing else is needed.
2. **A keyboard player no longer loses their place.** A guessed letter's on-screen key is disabled, so a player using Tab and Enter lost focus after every guess.
   - Focus now moves to the next key still free.
   - When the game ends, focus moves to the end card.
   - `tools/lantern-play.ts` checks this after every guess.
3. **The label.** The prototype label is gone from the page and from the game's card on the museum's games page. The page now says the four daily games are finished, in all seven languages.

**The fixes made for the other daily games apply here too:** the contrast fixes and the per-script fonts (Arabic in Naskh, Urdu in Nastaliq).

## Checks run

All checks ran on this machine against the local host (`tools/local-host.ts` over `dist/release`). None ran against UAT or production.

- **`tools/lantern-play.ts` (new):** 56 runs, no problem found ([`lantern-play-2026-11-28.json`](lantern-play-2026-11-28.json)).
  - **How it plays:** whole days with the keyboard alone. The first letter is typed on the keyboard; every other guess is Enter on the on-screen key.
  - **Coverage:**
    - 7 languages;
    - a phone (375×812, touch) and a desktop (1440×900);
    - light and dark;
    - once lit by guessing the name's letters, and once burnt out by seven wrong letters;
    - the puzzle of 1 December 2026.
  - **Each run checks:**
    - the page's direction;
    - that focus stays on a usable element after every guess;
    - the end card, and its museum link;
    - no sideways scroll at phone width;
    - that the finished day is kept after a reload;
    - no console error;
    - that every visible text has 4.5:1 contrast.
  - **Exempt from the contrast check:**
    - disabled keys, which WCAG exempts as inactive controls;
    - the oil drops, which are decoration hidden from assistive technology. Their count is stated as text ("drops left"), and that text is checked.
  - **Captures:** Arabic, English and Urdu on a phone, light and dark, both endings, are kept here. Arabic and Urdu were looked at by eye.
- **Unit tests:** `npm --prefix gaming test` covers 400 days of names in every language. Each day's name is the same for everyone, can be solved, and is a museum record with a source.

## What a person should check next

1. **A playtest:** play a week of days on a real phone, in Arabic and in English.
2. **Native readers:** have native speakers read the Urdu, Turkish and Indonesian strings and names.
3. **A screen reader:** run VoiceOver or TalkBack through one whole day. The name's state is read through its label, and each guess through a live region.
