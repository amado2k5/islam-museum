# About this copy

This folder is the founder's `granada-production-package.zip` of 25 November 2026, copied into the repository so that a later session has it. All 19 files matched `PACKAGE-CHECKSUMS.sha256` before copying.

It differs from the package in three ways, so the checksum list (kept as `PACKAGE-CHECKSUMS.sha256.orig`) will not verify against this folder as it stands:

1. The three concept images in `assets/` are reduced to 1280 × 720 so that no file is over 300 KB. The originals are in the founder's package.
2. `reference/islam-museum-gaming-platform-v2.zip` is not here. Its SHA-256 is that of the Version 2 package already unpacked in [`../spec-v2/`](../spec-v2/).
3. This note was added.

Nothing in the documents or the contracts was edited. What was found on reading them, and where the package and the repository differ, is in [`../granada/g0-discovery.md`](../granada/g0-discovery.md). The real status of the gates is kept in [`../granada/acceptance.md`](../granada/acceptance.md), never in `contracts/acceptance.json` here.

The images are concept art supplied with the design. None is a capture of a game and none is evidence of anything historical.
