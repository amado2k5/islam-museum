# Modern Islam Browser: the seed programme (the first 10,000 to 50,000 subjects)

Every name below is a **lead, not a fact**. Names are spelled as they are commonly found; nothing here is sourced, dated or confirmed, and nothing enters the museum until an agent has read a defined source for it in the browser and registered that source. A lead that cannot be sourced stays a lead. A lead whose subject turns out to be out of scope is closed with a reason, a gate and an override line in the progress file. Faith is never inferred from a name on this list; `made.by_muslims` is never set from this list.

The lists are deliberately broad in country and language so the browser is not a browser of one country. Each section has: the **pilot** (one record for the first production push, with alternates), the **targets**, the **named leads** to start the waves, and the **generators** that produce the rest in the browser.
