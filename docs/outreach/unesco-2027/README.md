## Privacy

This repository is public. These files name organisations, public offices, former laureates of the Prize, and scholars who agreed to be quoted or are named on the museum's own Network page. People who only answered a first letter in the last few days are described by their institution, not by name. The files carry no personal email address, telephone number or home address; letter drafts use `[email]` and `[telephone]`. One reply (ICDE's) carries a confidentiality notice and is paraphrased, never quoted.
