# Delegation: progress files and history

Instructions for agents are vendor-neutral and live in [`../agents/`](../agents/README.md) (start at [`../../AGENTS.md`](../../AGENTS.md)); lanes are registered in [`../agents/lanes.md`](../agents/lanes.md). This folder holds what changes as work proceeds:

- `<lane>-progress.md`: the hand-off trail of each lane (sections done with pages, section in progress, flagged doubts, the exact next step): [`raheeq-progress.md`](raheeq-progress.md), [`hisham-progress.md`](hisham-progress.md), and `library/<book-id>.md` for each library book.
- [`held-back-content.md`](held-back-content.md): the backlog of content the old source rules kept out of the museum (books mined for facts only, summary-only entities, unmined library, withheld texts), one lane per session, to be worked through under `docs/sources-policy.md`.
- [`gap-batches.md`](gap-batches.md): the plan of what the museum still lacks, from Arabic Wikipedia (discovery only).
- [`devin-people-lane.md`](devin-people-lane.md): the original prompt of the completed Prophetic-era people lane, kept as a record. It predates the Arabic-first, Sunni-first and attribution-trailer rules: follow `AGENTS.md`.

The earlier per-vendor prompts (Antigravity, Kiro, Codex) were merged into the vendor-neutral documents and removed; their lane-specific content is in `../agents/lanes/`.
- [local-model-library-prompt.md](local-model-library-prompt.md): paste-able prompt to process the downloaded library on the founder's Mac with local models (Ollama), vendor-neutral.
- [education-master-plan.md](education-master-plan.md): Stage 1 audit and phased plan (E1–E5) for the education programme (five age bands, teacher and parent surfaces, trilingual), with mockups in `../design/education/`; awaiting the founder's phase-by-phase approval (23 October 2026).
